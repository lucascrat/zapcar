# 🚀 Sistema de Atualização Automática - ZapCar

Este projeto está configurado para se manter sempre atualizado com o repositório GitHub.

## 📋 Como Usar

### Atualização Manual (Recomendado)

Execute o script de atualização:

```powershell
.\update.ps1
```

### O que o Script Faz

1. ✅ Salva suas alterações locais
2. ✅ Busca código novo do GitHub
3. ✅ Baixa atualizações
4. ✅ Instala dependências
5. ✅ Compila o projeto

## 💡 Comandos Úteis

```bash
# Atualizar do GitHub
.\update.ps1

# Ver status
git status

# Enviar alterações
git add .
git commit -m "Sua mensagem"
git push origin main
```
